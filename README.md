# Corona Virus VR Game

![Game Banner](https://via.placeholder.com/1200x300)

## 🦠 Overview

Corona Virus VR Game is an immersive Virtual Reality experience that puts players inside the bloodstream to battle viruses. Taking inspiration from the pandemic, this fast-paced game transforms a serious topic into an engaging and interactive adventure.

Players become defenders of the body, armed with virtual injectors to eliminate invading viruses with precision and skill. Built with Unity and optimized for Oculus headsets, the game offers an exhilarating battle for immunity that's both entertaining and unique.

## ✨ Features

- **Immersive VR Experience**: Fully-immersive gameplay designed specifically for VR headsets
- **Dynamic Virus Movement**: Viruses move with randomized patterns and realistic physics
- **Dual-Wielding Gameplay**: Control injectors with both hands for maximum virus-fighting capability
- **Realistic Feedback**: Enjoy haptic vibrations and visual effects that enhance immersion
- **Intuitive Controls**: Simple "point and shoot" mechanics that are easy to learn but challenging to master

## 🎮 Gameplay

1. **Start Screen**: One-click launch into the VR experience
2. **Loading Screen**: Quick transition into the bloodstream battlefield
3. **Main Game**: Eliminate all viruses using your injectors
4. **Victory**: Reach immunity by destroying all virus threats

## 🧬 Technical Details

### Core Scripts

- **Game Manager**: Controls virus spawning, win conditions, and overall game state
- **Virus Behavior**: Manages random movement, collision, and destruction of virus entities
- **Wall Bounce**: Handles realistic physics when viruses hit boundaries
- **Injector Control**: Powers the dual-wielding shooting mechanics
- **Explosion Effects**: Creates and manages visual feedback when viruses are destroyed

### Built With

- Unity Game Engine
- Oculus Integration Package
- Custom 3D models and effects

## 📋 Requirements

- Oculus VR headset (Quest, Rift, etc.)
- Enough play space for arm movement
- Strong stomach for intense VR action!

## 🚀 Installation
